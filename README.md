# Планировщик и автопостинг

Свой планировщик постов для сети школ: календарь, композер с превью под каждую
площадку и очередь публикации в Telegram, Threads, Instagram, Facebook и TikTok.

Делается **для себя**. Продажа агентствам — потом и отдельно; поэтому здесь нет
мультиарендности, шифрования чужих токенов и всего, что нужно посреднику.

## Что уже работает

- Календарь недели, черновики без даты, карточки со статусом по каждой площадке.
- Композер: общий текст, счётчики символов под лимит каждой площадки, выбор
  раскладок, загрузка мастер-медиа.
- **Превью с безопасными зонами** — видно, что перекроют кнопки площадки,
  и как портрет обрежется в сетке профиля Instagram.
- **Проверка перед очередью**: блокеры (площадка не примет) отдельно от
  предупреждений (примет, но выйдет плохо).
- Очередь и воркер публикации, журнал попыток, повтор без дублей.
- Адаптер **Telegram** — рабочий. Остальные написаны по документации, но живым
  токеном не проверены: до первого успешного поста считать черновиком.

## Как идёт работа

```
тренд  →  идея в плане  →  утверждение  →  пост-заготовка  →  очередь  →  сети
```

1. **Тренды** — сигналы: что сейчас заходит. Автоматически собираются только
   Google Trends, «в тренде» у YouTube и наша статистика по вышедшим постам.
   **У Instagram, Facebook и TikTok публичного API трендов нет** — туда сигнал
   заносится разбором: руками в панели или `tools/trends-import.mjs`.
2. **Контент-план** — доска по состояниям: идея → утверждена → в работе →
   опубликована. В карточке есть строка «что нужно снять»: ради неё СММщик
   и открывает план.
3. Из утверждённой идеи **пост-заготовка** создаётся одним нажатием: тема,
   тезисы и площадки переносятся, СММщику остаётся подложить кадр.
4. Дальше обычный путь поста: проверка, очередь, публикация.

Тренды протухают. Сигнал старше трёх недель (или своего срока) помечается
и уводится вниз: по нему делают контент, который выглядит вчерашним.

## Надёжность

Отправкой занимается только воркер — веб-морда ставит в очередь и отвечает
сразу. Отметка о начале отправки ставится ДО вызова площадки: если процесс
умрёт посреди запроса, пост не повторяется молча, а помечается «неизвестно,
ушло ли» и ждёт человека. Повторить вслепую — значит однажды опубликовать
дубль в пяти сетях, а его заметят подписчики, а не мы.

`npm test` — 29 проверок: выборка очереди, разбор зависших, шифрование
доступов, изоляция проектов, слоты, подмена ссылок.

## Слоты и рубрики

Сетка «пн, ср, пт в 10:00 и 18:30» задаётся один раз на проект, дальше пост
кладётся в ближайший свободный слот одной кнопкой. Рубрика — очередь со
своим ритмом; помеченная «вечнозелёной» возвращает пост в оборот копией
через заданное число дней, не трогая оригинал в истории.

## Переходы и заявки

Ссылки на наши сайты подменяются короткими: они считают переход и проставляют
метки, сайт кладёт метки в заявку (поля `utm_*` там уже есть), панель
сопоставляет заявки с постом по `utm_campaign`. Это то, чего не даёт ни один
сервис планирования: у них нет наших заявок.

Чужие ссылки не трогаем, проставленные вручную метки не перетираем.

## Чего ещё нет

- Нарезки мастер-медиа под раскладки (ffmpeg) — ждут второй машины.
- Перекодирования видео и Reels у Facebook.
- Сторожа на протухание токенов — таблица `token_health` заведена, опрос не написан.
- Аналитики опубликованного.
- Автосбора трендов: Google Trends и YouTube подключаются, наша статистика —
  после того, как появятся токены площадок.

## Запуск

```
npm install
cp .env.example .env      # заполнить хотя бы Telegram
npm start                 # веб-морда, по умолчанию :3210
npm run worker            # воркер очереди, отдельным процессом
```

Node 22 и новее: хранилище — встроенный в Node SQLite, нативных сборок нет,
выкатка сводится к `git pull && npm ci`.

## Устройство

```
src/platforms/specs.js   Единый справочник площадок: раскладки, лимиты, зоны.
                         Отсюда живут и превью, и валидатор, и подписи.
src/platforms/*.js       Адаптеры. Общий вид: isConfigured / check / publish.
src/validate.js          Блокеры и предупреждения. Своих цифр не держит.
src/queue/publish.js     Отправка одного поста по всем площадкам.
src/queue/worker.js      Раз в минуту забирает созревшее.
src/media.js             Хранение мастер-медиа, размеры кадра, расчёт кропа.
public/                  Интерфейс без сборки.
```

Правило: **никаких цифр лимитов вне `specs.js`**. Площадки их меняют, и
разъехавшиеся копии — самый быстрый способ получить «пост не ушёл, а почему —
непонятно».
