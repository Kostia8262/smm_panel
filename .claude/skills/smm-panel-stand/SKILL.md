Стенд панели собирался заново три раза за один день (19.10.2026, работа над ботом-консультантом),
и каждый раз — одни и те же четыре переменные, порядок «сотрудник до сервера» и гашение по порту.
Здесь готовый порядок: от пустой папки до погашенного порта.

## Вход

Что проверяем (экран, ручка API, фича), нужна ли телефонная ширина, нужен ли взгляд
СММщика, а не только владельца. Ничего не дали — поднимай стенд владельцем и смотри
тот экран, который только что правил.

## Железные правила

1. **База только одноразовая.** Боевая `data/smm.db` для осмотра не годится: боевой
   `data/secret.key` классификатор расшифровать не даёт, а запись в боевое — это посты
   в реальные сети. Папка стенда — в scratchpad сессии, не в репозитории.
2. **Сотрудников заводить ДО старта сервера.** При нулевом числе сотрудников сервер сам
   зовёт `ensureOwner` и пишет токен владельца в `data/owner-token.txt` **внутри
   репозитория** (`src/server.js:219`, путь прошит и переменными не переносится). Заводишь
   заранее — файл не появляется, дерево остаётся чистым.
3. **Свой порт, не 3210.** Дефолтный держит стенд соседней вкладки. Бери 33xx.
4. **Гасить по порту или PID, никогда по имени процесса** — `node` в системе не один,
   и по имени падает чужой стенд.
5. **Воркер отдельно и только один.** `npm run worker` — второй процесс; двух воркеров
   на одну базу не поднимать (возьмут один пост дважды). Для осмотра интерфейса воркер
   обычно не нужен вовсе.
6. **Правку исходника не писать через heredoc.** `bash -c` с heredoc съедает уровень
   экранирования даже в кавычках: 19.10 дважды в исходник бота молча уехал управляющий
   символ (`\1` стал 0x01, `\n` — настоящим переводом строки), файл при этом разбирался
   и тесты шли. Править файлы инструментом Write/Edit; если без скрипта никак — собирать
   слэш через `String.fromCharCode(92)` и после правки проверять, что в файле нет байтов
   `< 32`, кроме перевода строки и табуляции.

## Порядок

1. **Папка стенда** — своя, в scratchpad сессии: `<scratchpad>/stand`.

2. **Сотрудники и переменные одной командой** (печатает JSON с токенами и путями):

   ```
   node .claude/skills/smm-panel-stand/scripts/seed-stand.mjs <scratchpad>/stand 3317
   ```

   В выдаче — `env` (четыре переменные), `tokens.owner`, `tokens.smm`, `start`, `url`.
   Скрипт откажется работать на непустой базе: стенд одноразовый.

3. **Старт сервера** с теми же переменными и своим портом, лог — в папку стенда:

   ```
   DB_PATH=<stand>/stand.db SECRET_KEY_PATH=<stand>/stand.key \
   UPLOAD_DIR=<stand>/uploads THUMB_DIR=<stand>/thumbs \
   PORT=3317 node src/server.js > <stand>/server.log 2>&1 &
   ```

   Дождаться готовности: `curl -s http://localhost:3317/healthz` → `{"ok":true,...}`.
   Пустой ответ — смотреть `server.log`, а не повторять запуск.

4. **Вход.** Токен обменивается на сессию в httpOnly-cookie `smm_session`:

   - через API: `curl -c <stand>/c.txt -X POST -H 'Content-Type: application/json'
     -d '{"token":"<owner>"}' http://localhost:3317/api/login` → 200, затем
     `curl -b <stand>/c.txt http://localhost:3317/api/me` показывает имя и роль;
   - в браузере: открыть `/login`, вставить токен в поле `#token`, нажать `#submit`.

   Токен не подошёл — 401; после нескольких промахов вход отвечает **429 на десять
   минут** (защита от перебора), так что токен копировать, а не набирать.

5. **Осмотр.** Снимок Playwright MCP плюс `getComputedStyle` через `browser_evaluate` —
   «проверял по разметке» владельца не устраивает. Телефон — `browser_resize` 375×812.
   Смотреть консоль и сеть: красное там считается находкой. `Browser is already in use`
   значит, что профиль держит соседняя сессия — переходить на Puppeteer MCP, не воевать.

6. **Взгляд СММщика.** Если правка касается прав, войти вторым токеном (`tokens.smm`) в
   отдельной вкладке: СММщику закрыты токены площадок, сотрудники и «Опубликовать сейчас».

7. **Уборка.** Погасить **свой порт**:

   ```
   netstat -ano | grep ":3317 " | grep LISTENING      # взять PID из последней колонки
   taskkill //PID <pid> //F                            # Git Bash: двойной слэш
   ```

   PowerShell: `Get-NetTCPConnection -LocalPort 3317 | Select-Object -Expand OwningProcess`,
   затем `Stop-Process -Id <pid> -Force`. Дальше `browser_close`. Папку стенда можно
   оставить в scratchpad — она исчезнет сама.

## Проверка перед сдачей

- `npm run check` (самопроверка площадок + `node --test`) — первый сигнал, не доказательство;
- экран осмотрен в браузере на полной и телефонной ширине, консоль чистая;
- `git status --short` в корне панели чист в части `data/` — ни `owner-token.txt`,
  ни боевой базы, ни ключа;
- порт погашен, в `netstat` нет своего LISTENING.

## Отчёт

Чем поднимался стенд (команда и порт), что смотрел, что увидел — с подтверждением
(код ответа, число из `getComputedStyle`, снимок). Отдельно: что не проверял и почему.
Правка интерфейса сдаётся только после осмотра в браузере.
