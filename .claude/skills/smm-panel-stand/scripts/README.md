# scripts — smm-panel-stand

| Скрипт | Что делает |
|---|---|
| `seed-stand.mjs <папка> [порт]` | Создаёт папку одноразового стенда, прогоняет миграции в пустой базе, заводит владельца и СММщика и печатает JSON: пути четырёх переменных, оба токена, команду старта и адрес входа |

Ничего не удаляет и в боевую базу не пишет: пути берутся только из аргумента.
На непустой базе выходит с кодом 2 — стенд одноразовый, нужна новая папка.

Почему сотрудники заводятся до старта сервера — в `../SKILL.md`, правило 2:
на пустой базе сервер сам пишет токен владельца в `data/owner-token.txt`
внутри репозитория.

Запускать из корня панели (`node .claude/skills/smm-panel-stand/scripts/seed-stand.mjs …`):
корень проекта скрипт находит сам, от своего расположения.
